# Bubble Fluff · 毛毡泡泡对战

A cozy felt-style bubble battle game that runs in the browser. It's a single HTML file, with nothing to install.

一款毛毡画风的泡泡对战小游戏，打开网页就能玩。

**▶ 在线游玩 / Play:** https://kapok1207-rgb.github.io/bubble-fluff/

## 玩法 / How to play

- **模式 / Modes:** 单人闯关、双人合作、双人对战、四人乱斗 (solo vs bots, co-op, 1v1, 4-player free-for-all)
- **玩家 1 / Player 1:** <kbd>↑</kbd><kbd>↓</kbd><kbd>←</kbd><kbd>→</kbd> 移动 · <kbd>Space</kbd> 放水泡 · <kbd>Shift</kbd> 用针
- **玩家 2 / Player 2:** <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> 移动 · <kbd>Enter</kbd> 放水泡 · <kbd>E</kbd> 用针
- **其他 / Other:** <kbd>P</kbd> 暂停 · <kbd>M</kbd> 静音 · <kbd>Esc</kbd> 菜单

大树和花坛炸不掉。小房子能炸开，里面可能藏着道具。被泡泡困住时，队友可以碰一下把你救出来，你也可以用针自救。
